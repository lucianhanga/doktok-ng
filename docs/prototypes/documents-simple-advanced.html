Draft epic breakdown

Sequenced so state and query behavior are fixed before the visual variants multiply.

  1. State and query contractVersion preferences, URL state, deep-link precedence, reset behavior, shared list/select-all filters.
  2. Simple shell and listGlobal mode wiring, selected row content, responsive table, layout switch, empty/loading states.
  3. Thumbnail systemResponsive cards, visible badges, processing summary, fallbacks, fields and sizes.
  4. Search and filteringChosen search scope, suggestions, filter disclosure/rail, removable chips, zero-result recovery.
  5. Ordering and navigationNamed sorts or multi-sort, stable cursors, Back/Forward, restored scroll and Load more.
  6. Advanced operationsSelection, bulk actions, reprocessing, column customization, full processing diagnostics.
  7. Accessibility and performanceKeyboard/focus, screen readers, mobile, reduced motion, large-library and query tests.
  8. Migration and rolloutPreference migration, regression coverage, staged PRs, final end-to-end verification.
